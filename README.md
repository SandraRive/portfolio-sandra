# Sandra Rivera | Portfolio

Portfolio profesional de Sandra Rivera, estudiante de Ingeniería Informática y desarrolladora Fullstack. Construido con HTML, CSS y JavaScript puro, sin frameworks.

🔗 **Demo en vivo:** [sandrarive.github.io/portfolio-sandra](https://sandrarive.github.io/portfolio-sandra/)

## 📋 Sobre el proyecto

Este portfolio no es una plantilla genérica: fue diseñado y desarrollado desde cero, sección por sección, con especial cuidado en:
- Contenido 100% real y verificado (sin inflar conocimientos ni proyectos)
- Accesibilidad (navegación por teclado, contraste WCAG AA, `prefers-reduced-motion`)
- Rendimiento (sin frameworks pesados, CSS modular)
- SEO básico (metadatos, Open Graph, semántica HTML)

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript (vanilla)
- **Fuentes:** Inter, JetBrains Mono (Google Fonts)
- **Control de versiones:** Git + GitHub
- **Deployment:** GitHub Pages

portfolio-sandra/

## ✨ Funcionalidades

- Efecto typewriter animado en el Hero
- Navegación responsive con menú hamburguesa en móvil
- Sección de Skills con niveles honestos de conocimiento (no inflados)
- Proyectos presentados como casos técnicos
- Formación con timeline y diplomas en desplegable
- Modo de contraste y accesibilidad auditado con Lighthouse (100/100 en Accesibilidad, SEO y Buenas Prácticas)

## 🎨 Decisiones de diseño

Se optó por una estética "Terminal Elegante": fondo oscuro, acento verde-lima y tipografía monoespaciada en detalles técnicos, evocando herramientas de desarrollo sin sacrificar profesionalidad ni legibilidad.

## 🚀 Cómo ejecutarlo en local

1. Clona el repositorio:
   \`\`\`
   git clone git@github.com:SandraRive/portfolio-sandra.git
   \`\`\`
2. Abre \`index.html\` con Live Server (extensión de VS Code) o directamente en tu navegador.
